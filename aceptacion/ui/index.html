Aceptación de presupuestos

El enlace se crea desde cada presupuesto emitido, con el botón «Enlace de aceptación».

La respuesta queda registrada con fecha, hora, IP y la copia del PDF exacto que vio el cliente. Es una evidencia de su conformidad, pero no una firma electrónica avanzada ni cualificada.

Configuración

Los clientes deben poder abrir esa dirección desde Internet. Si la dejas vacía, se usa la dirección con la que entras ahora.
