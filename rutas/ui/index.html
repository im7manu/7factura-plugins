7Ruta

Calcula rutas y kilómetros con vista previa en el mapa. Los usa el plugin «7DeCA» para facturar por kilómetro.

Solo un administrador puede cambiar la configuración.

Proveedor de mapas

  1. Crea una cuenta gratuita en account.heigit.org (OpenRouteService).
  2. Copia tu clave de API y pégala aquí.
Direcciones del servicio (avanzado)
  1. En Google Cloud, activa Routes API, Geocoding API y Maps JavaScript API.
  2. Crea una clave de servidor (restringida a esas API y a la IP del servidor) y una clave de navegador (restringida a la dirección de 7Factura).
