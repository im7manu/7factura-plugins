WhatsApp

Envía los PDF de tus documentos por WhatsApp desde el número de la empresa.

WhatsApp Web no es la API oficial de Meta: puede dejar de funcionar si WhatsApp cambia su web, y la sesión puede caducar y pedir volver a vincular el teléfono. Úsalo para enviar documentos de uno en uno, nunca envíos masivos. Esta conexión es independiente del WhatsApp que usa 7Factura para recuperar contraseñas.

Variables: {cliente}, {empresa}, {numero}, {fecha}, {total}, {vencimiento}, {vencimiento_txt}, {tipo}, {el_documento}, {importe}. El texto se puede cambiar antes de cada envío.

Solo un administrador puede cambiar los mensajes.
